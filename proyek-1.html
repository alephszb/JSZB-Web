Konfigurasi Hotspot MikroTik

Latihan membangun hotspot dengan limitasi bandwidth dan halaman login.

Langkah-langkah sederhana untuk membuat jaringan hotspot MikroTik: perangkat pengunjung harus login dulu ke halaman beranda, dan bandwidth tiap pengguna dibatasi agar koneksi tetap nyaman.

> SYS.01_REQ

Router MikroTik

RouterBoard atau PC RouterOS. Contoh ini pakai 2 port: ether1 untuk internet, ether2 untuk hotspot.

> SYS.01_REQ

Koneksi Internet

Modem ISP sebagai sumber internet, disambung kabel LAN ke ether1.

> SYS.01_REQ

PC + Winbox

Untuk mengatur router. Bisa juga pakai SSH atau WebFig dari browser.

> SYS.01_REQ

Akses Client

Access Point WiFi atau kabel LAN ke ether2 agar perangkat pengunjung bisa terhubung.

STEP.01

Beri nama router & ambil internet dari modem

Pastikan ether1 sudah dicolok ke modem ISP. Buka Winbox, masuk menu Terminal, lalu jalankan:

TERMINAL // MIKROTIK
/system identity set name=Hotspot-Warkop
/ip dhcp-client add interface=ether1 disabled=no
STEP.02

Beri IP untuk jaringan lokal & DNS

IP ini yang nanti dipakai client saat terkoneksi (gerbang hotspot). Ganti angka terakhir jika bentrok dengan jaringan modem.

TERMINAL // MIKROTIK
/ip address add address=192.168.100.1/24 interface=ether2
/ip dns set servers=8.8.8.8,1.1.1.1 allow-remote-requests=yes
STEP.03

Aktifkan DHCP Server

Supaya perangkat client dapat IP otomatis tanpa disetel manual.

TERMINAL // MIKROTIK
/ip pool add name=pool-hotspot ranges=192.168.100.10-192.168.100.200
/ip dhcp-server add name=dhcp-hotspot interface=ether2 address-pool=pool-hotspot
/ip dhcp-server network add address=192.168.100.0/24 gateway=192.168.100.1 dns-server=192.168.100.1
/ip dhcp-server enable dhcp-hotspot
STEP.04

Aktifkan Hotspot & buat user login

Halaman login bawaan MikroTik sudah tersedia otomatis. Buat satu akun pengguna untuk mencoba.

TERMINAL // MIKROTIK
/ip hotspot add name=hotspot1 interface=ether2
/ip hotspot server profile set [ find ] hotspot-address=192.168.100.1
/ip hotspot user add name=tamu password=12345
STEP.05

Batasi bandwidth per pengguna

Format rate-limit adalah download/upload. Contoh di bawah: tiap pengguna maksimal 5 Mbps unduh dan 2 Mbps unggah.

TERMINAL // MIKROTIK
/ip hotspot server profile set [ find ] rate-limit=5M/2M
STEP.06

Uji coba

Hubungkan HP/PC ke ether2 (via AP WiFi atau kabel), lalu buka alamat apa saja di browser. Halaman login hotspot akan muncul.

CEK // LANGKAH
1. Browser menampilkan halaman login hotspot?
2. Login dengan tamu / 12345 berhasil?
3. Internet jalan & kecepatan dibatasi?
Tambah user baru: Winbox > IP > Hotspot > Users > Tambah
SYS.01

Semua perintah sekaligus

Salin semua perintah di bawah, tempel ke Terminal Winbox, tekan Enter. Urutan sudah benar dari atas ke bawah.

TERMINAL // MIKROTIK 
# 1. Identitas router
/system identity set name=Hotspot-Warkop
# 2. ether1 terima internet dari modem
/ip dhcp-client add interface=ether1 disabled=no
# 3. IP lokal & DNS
/ip address add address=192.168.100.1/24 interface=ether2
/ip dns set servers=8.8.8.8,1.1.1.1 allow-remote-requests=yes
# 4. DHCP server
/ip pool add name=pool-hotspot ranges=192.168.100.10-192.168.100.200
/ip dhcp-server add name=dhcp-hotspot interface=ether2 address-pool=pool-hotspot
/ip dhcp-server network add address=192.168.100.0/24 gateway=192.168.100.1 dns-server=192.168.100.1
/ip dhcp-server enable dhcp-hotspot
# 5. Hotspot + user login
/ip hotspot add name=hotspot1 interface=ether2
/ip hotspot server profile set [ find ] hotspot-address=192.168.100.1
/ip hotspot server profile set [ find ] rate-limit=5M/2M
/ip hotspot user add name=tamu password=12345
> Selesai jika: perangkat client menampilkan halaman login saat membuka browser, internet jalan setelah login dengan tamu / 12345, dan kecepatan terbatas sesuai rate-limit.
