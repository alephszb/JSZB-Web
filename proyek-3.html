Website Portofolio Sendiri

Website portofolio sederhana yang kamu lihat ini, dibuat dari nol.

Cara membuat website portofolio dari nol: tiga bagian (HTML, CSS, JS), tanpa framework, jalan di browser, lalu siap di-deploy online.

> SYS.03_REQ

Editor Kode

VS Code, Notepad++, atau editor apa pun untuk menulis kode.

> SYS.03_REQ

Browser

Untuk melihat hasil halaman yang sedang dibuat.

> SYS.03_REQ

XAMPP / PHP

Opsional, untuk menjalankan server lokal saat mengembangkan.

> SYS.03_REQ

GitHub + Vercel

Opsional, untuk menyimpan kode dan publish website ke internet.

STEP.01

Buat struktur folder

Satu folder berisi tiga bagian: HTML untuk isi, CSS untuk tampilan, JS untuk perilaku. Semua halaman saling terhubung.

STRUKTUR // FOLDER
portofolio/
|-- index.html
|-- tentang.html
|-- proyek.html
|-- kontak.html
|-- css/
|   `-- style.css
`-- js/
    `-- script.js
STEP.02

Tulis halaman dasar HTML

Kerangka tiap halaman. File CSS dipanggil di head, file JS di akhir body.

KODE // HTML
<!DOCTYPE html>
<html lang="id">
<head>
  <title>Portofolio</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <h1>Halo!</h1>
  <script src="js/script.js"></script>
</body>
</html>
STEP.03

Jalankan di browser / server lokal

Buka index.html langsung, atau pakai server lokal agar jalur CSS/JS selalu benar.

TERMINAL // LOKAL
php -S localhost:8000

Lalu buka http://localhost:8000 di browser.

STEP.04

Edit & lihat hasil

Ubah file lalu refresh browser. Terapkan satu tema yang konsisten di semua halaman agar terlihat profesional.

CATATAN // DESAIN
1. Gunakan palet warna yang sama di semua halaman
2. Navbar & footer sama di tiap halaman
3. Perhatikan halaman HP (responsive)
STEP.05

Deploy online (opsional)

Simpan kode ke GitHub lalu hubungkan ke Vercel. Setiap push ke main otomatis ter-deploy.

TERMINAL // GIT
git init
git add -A
git commit -m "Website portofolio"
git push origin main
STEP.06

Uji coba

CEK // LANGKAH
1. Browser menampilkan halaman + CSS & JS termuat?
2. Semua halaman (tentang, proyek, kontak) terbuka?
3. Tampilan konsisten (satu tema)?
4. (Opsional) Situs sudah online di Vercel?
