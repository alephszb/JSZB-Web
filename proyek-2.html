Web Server di Linux

Latihan instalasi dan konfigurasi Apache & PHP di server Linux.

Cara sederhana membangun web server di Linux: pasang Apache + PHP lewat terminal, lalu tampilkan halaman yang bisa diakses dari browser.

> SYS.02_REQ

Server Linux

Ubuntu/Debian, bisa VPS atau mesin virtual. Perlu akses root/sudo lewat SSH.

> SYS.02_REQ

Koneksi Internet

Dibutuhkan saat mengunduh paket lewat apt.

> SYS.02_REQ

PC Admin

Untuk masuk SSH ke server dan membuka halaman web di browser.

> SYS.02_REQ

IP / Domain

Alamat server untuk mengakses situs, misalnya http://IP-SERVER.

STEP.01

Update sistem dulu

Perbarui daftar paket agar semua yang diinstall selalu versi terbaru. Prosesnya bisa berjalan beberapa menit.

TERMINAL // LINUX
sudo apt update && sudo apt upgrade -y
STEP.02

Install Apache & PHP

Apache adalah web server-nya, PHP untuk membuat halaman dinamis.

TERMINAL // LINUX
sudo apt install apache2 php libapache2-mod-php -y
STEP.03

Nyalakan & aktifkan otomatis

Pastikan Apache berjalan dan ikut menyala otomatis saat server dinyalakan. Tekan q untuk keluar dari tampilan status.

TERMINAL // LINUX
sudo systemctl start apache2
sudo systemctl enable apache2
systemctl status apache2
STEP.04

Izinkan HTTP di firewall

Lewati langkah ini jika tidak memakai firewall ufw.

TERMINAL // LINUX
sudo ufw allow 'Apache'
STEP.05

Buat halaman tes PHP

Tulis file index.php di folder web default /var/www/html. Ganti isinya dengan halaman milikmu.

TERMINAL // LINUX
echo "<?php echo 'Server OK'; ?>" | sudo tee /var/www/html/index.php
STEP.06

Uji coba

Cari tahu alamat IP server dengan perintah di bawah, lalu buka alamat tersebut di browser.

TERMINAL // LINUX
hostname -I
CEK // LANGKAH
1. Browser menampilkan "Server OK"?
2. Status Apache active (running)?
3. Halaman PHP benar-benar berjalan?
SYS.02

Semua perintah sekaligus

Salin semua perintah di bawah, tempel ke terminal, tekan Enter. Urutan sudah benar dari atas ke bawah.

TERMINAL // LINUX 
# 1. Update sistem
sudo apt update && sudo apt upgrade -y

# 2. Install Apache + PHP
sudo apt install apache2 php libapache2-mod-php -y

# 3. Nyalakan & aktifkan otomatis
sudo systemctl start apache2
sudo systemctl enable apache2

# 4. Izinkan HTTP (lewati jika tidak pakai ufw)
sudo ufw allow 'Apache'

# 5. Halaman tes
echo "<?php echo 'Server OK'; ?>" | sudo tee /var/www/html/index.php
> Selesai jika: browser menampilkan Server OK, status Apache active (running), dan halaman PHP berjalan dengan benar.
